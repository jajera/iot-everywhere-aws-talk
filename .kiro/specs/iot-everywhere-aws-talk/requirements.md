# Requirements (talk)

## Goals

1. Deliver a ~20 minute high-level AWS community talk on everyday IoT and one device path to AWS IoT Core.
2. Keep slides visual, neutral in tone, and safe for live demo constraints.
3. Live beat shows a pre-opened Amplify dashboard while boards publish in the background.
4. Ship Slidev to GitHub Pages; keep `demo/` as a thin backbone (firmware + CLI cloud path + Amplify UI).

## Non-goals

- Full lab or Terraform in this repository
- Live AWS console operation on stage
- Deep seismic / GNSS tutorials

## Constraints

- Neutral language at all times (`.kiro/steering/neutral-language.md`)
- No unsolicited AWS mutations (`.kiro/steering/lab-safety.md`)
- AWS behaviour claims sourced (`.kiro/steering/aws-source-lock.md`)
